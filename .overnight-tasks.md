# Overnight Task Queue

Add one task per line in this exact format (without the leading `#`):
#   - [ ] READY: build the retargeting pixel admin settings page

The overnight run (1am-9am MST) only processes lines starting with `- [ ] READY:`.
It never invents work on its own. After a task finishes, its line is rewritten
to `- [ ] DONE:`, `- [ ] NO-CHANGE:` (nothing was actually produced -- needs a
human look), or left as `- [ ] READY:` (the build step itself failed -- see
the night's log under .overnight-logs/).
