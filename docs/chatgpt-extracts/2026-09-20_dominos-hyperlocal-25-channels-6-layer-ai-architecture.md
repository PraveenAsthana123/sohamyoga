## Key Architectural Insights

1. **Don't rebuild Domino's POS** — integrate around it; own customer communication/marketing, not ordering
2. **B2B = highest LTV channel** — offices, hotels, schools, sports clubs, apartments generate recurring high-value orders
3. **Unified telemetry chain**: `Opportunity_ID → Decision_ID → Agent_Run_ID → Model_Call_ID → Campaign_ID → Outcome_ID`
4. **Human Acceptance Rate (HAR)** = key AI quality signal; drop from 90% → 55% means something broke
5. **AI unit economics**: Cost-per-order, cost-per-$100 revenue must be tracked or AI spend is invisible
6. **Fail-closed rule**: consent unavailable → BLOCK; trend analyzer unavailable → continue without feature
7. **Prompt versioning = software release**: compare P1 vs P2 vs P3 on grounding%, acceptance%, tokens, cost, latency
8. **Shadow mode** before live deployment for high-risk agents — recommend without executing, compare to human decisions
9. **Concept drift**: model trained on 'Friday = peak' may break when Sunday becomes peak — must monitor outcome drift
10. **AI FinOps**: baseline $0.07/agent-run → alert if it jumps to $0.21 (larger context, extra tool calls, cache miss)
