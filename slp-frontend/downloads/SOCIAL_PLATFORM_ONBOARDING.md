# Social Platform Developer Onboarding Checklist
# Soham Yoga Portal — Postiz Integration

SECURITY RULES — READ FIRST:
- Never paste passwords, MFA codes, or OAuth tokens into this file
- Developer App credentials (App ID / Client ID) = OK to save in .env.example placeholders
- App Secrets = save in OpenBao (slp-portal/<platform>), NOT in .env committed to git
- OAuth access/refresh tokens = generated by Postiz OAuth flow, stored encrypted in Postiz DB

Recommended setup order (simplest → most complex):
  Telegram → Discord → Bluesky → Reddit → YouTube → Pinterest
  → Facebook/Instagram/Threads → LinkedIn → X → TikTok

Post-setup for each: restart Postiz → Settings → Social Accounts → Connect [Platform]

────────────────────────────────────────────────────────────────────────────
1. TELEGRAM (Simplest — no developer portal signup)
────────────────────────────────────────────────────────────────────────────
Type: Bot token (not OAuth)
Review required: No
Setup time: ~5 minutes

Steps:
  1. Open Telegram app
  2. Search for @BotFather
  3. Send: /newbot
  4. Enter bot name: SohamYogaBot (or your choice)
  5. Enter bot username: sohamyoga_bot (must end in _bot)
  6. Copy the token BotFather gives you (format: 1234567890:AAFxxx...)
  7. Add bot as Admin to your Telegram channel/group
  8. Save token in OpenBao: `bao kv put slp-portal/telegram token=<paste>`
  9. Set in .env: TELEGRAM_BOT_TOKEN=<same token>

Env vars:
  TELEGRAM_BOT_TOKEN=<from BotFather>

────────────────────────────────────────────────────────────────────────────
2. DISCORD (Webhook OR OAuth app)
────────────────────────────────────────────────────────────────────────────
Type: OAuth 2.0 app + Bot, OR Webhook URL
Review required: No
Setup time: ~10 minutes

Option A — Webhook (simplest):
  1. Open Discord server
  2. Server Settings → Integrations → Webhooks → New Webhook
  3. Select channel, copy webhook URL
  4. Save in OpenBao: `bao kv put slp-portal/discord_webhook url=<paste>`
  5. Set in .env: DISCORD_WEBHOOK_URL=<url>

Option B — OAuth app:
  1. Go to discord.com/developers/applications
  2. New Application → name it "Soham Yoga"
  3. Bot tab → Add Bot → copy token
  4. OAuth2 tab → Redirects → Add: http://localhost:3000/api/socials/discord/callback
  5. Copy Client ID and Client Secret
  6. Save secret in OpenBao: `bao kv put slp-portal/discord secret=<paste>`

Env vars:
  DISCORD_CLIENT_ID=<application id>
  DISCORD_CLIENT_SECRET=<from OpenBao>

────────────────────────────────────────────────────────────────────────────
3. BLUESKY (App Password — no developer app)
────────────────────────────────────────────────────────────────────────────
Type: Handle + App Password
Review required: No
Setup time: ~3 minutes

Steps:
  1. Log in to bsky.app
  2. Settings → Privacy and Security → App Passwords
  3. Add App Password → name: "Postiz"
  4. Copy the generated password (NOT your main password)
  5. Save in OpenBao: `bao kv put slp-portal/bluesky app_password=<paste>`
  6. Set in .env: BLUESKY_APP_PASSWORD=<app password>
  7. In Postiz UI, set your Bluesky handle (e.g. yourname.bsky.social)

Env vars:
  BLUESKY_APP_PASSWORD=<from OpenBao>

────────────────────────────────────────────────────────────────────────────
4. REDDIT
────────────────────────────────────────────────────────────────────────────
Type: OAuth 2.0 web app
Review required: No (personal use)
Setup time: ~10 minutes

Steps:
  1. Log in to reddit.com
  2. Go to reddit.com/prefs/apps
  3. Click "create another app" → select "web app"
  4. Name: Soham Yoga Portal
  5. Redirect URI: http://localhost:3000/api/socials/reddit/callback
  6. Submit → copy the Client ID (under app name) and Secret
  7. Save secret in OpenBao: `bao kv put slp-portal/reddit secret=<paste>`

Env vars:
  REDDIT_CLIENT_ID=<client id>
  REDDIT_CLIENT_SECRET=<from OpenBao>

────────────────────────────────────────────────────────────────────────────
5. YOUTUBE (Google Cloud Console)
────────────────────────────────────────────────────────────────────────────
Type: Google OAuth 2.0
Review required: No (for personal channel; verification for large quotas)
Setup time: ~20 minutes

Steps:
  1. Go to console.cloud.google.com
  2. Create project: "Soham Yoga Portal"
  3. APIs & Services → Library → search "YouTube Data API v3" → Enable
  4. APIs & Services → OAuth consent screen:
     - User Type: External → Fill in app name, your email
     - Scopes: Add "YouTube Data API v3" scopes
     - Test users: add your Google account email
  5. APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client ID
     - Application type: Web application
     - Authorized redirect URIs: http://localhost:3000/api/socials/youtube/callback
  6. Copy Client ID and Client Secret
  7. Save secret in OpenBao: `bao kv put slp-portal/youtube secret=<paste>`

Env vars:
  YOUTUBE_CLIENT_ID=<client id>
  YOUTUBE_CLIENT_SECRET=<from OpenBao>

────────────────────────────────────────────────────────────────────────────
6. PINTEREST
────────────────────────────────────────────────────────────────────────────
Type: OAuth 2.0
Review required: No (standard access)
Setup time: ~15 minutes

Steps:
  1. Go to developers.pinterest.com
  2. My Apps → Create App
  3. App name: Soham Yoga Portal
  4. Website: your domain
  5. Redirect URI: http://localhost:3000/api/socials/pinterest/callback
  6. Permissions: boards:read, boards:write, pins:read, pins:write
  7. Copy App ID and App Secret
  8. Save secret in OpenBao: `bao kv put slp-portal/pinterest secret=<paste>`

Env vars:
  PINTEREST_CLIENT_ID=<app id>
  PINTEREST_CLIENT_SECRET=<from OpenBao>

────────────────────────────────────────────────────────────────────────────
7. FACEBOOK PAGES + 8. INSTAGRAM + 9. THREADS (One Meta app for all three)
────────────────────────────────────────────────────────────────────────────
Type: Meta/Facebook OAuth 2.0 Business App
Review required: YES — App Review required for public use
Setup time: 1-2 weeks (review duration varies)

Pre-requisite:
  - Facebook Page exists (you have this)
  - Instagram Business account linked to your Facebook Page
  - Meta Business Suite verified (recommended)

Steps:
  1. Go to developers.facebook.com
  2. My Apps → Create App → Business → Continue
  3. App name: Soham Yoga Portal
  4. App contact email: your email
  5. In app dashboard → Add Products:
     - Facebook Login for Business
     - Instagram Graph API
     - Threads API (if available in your region)
  6. Facebook Login → Settings:
     - Valid OAuth Redirect URIs: http://localhost:3000/api/socials/facebook/callback
  7. Instagram → Settings:
     - Redirect URI: http://localhost:3000/api/socials/instagram/callback
  8. App Settings → Basic:
     - Copy App ID and App Secret
  9. App Review:
     - Request permissions: pages_manage_posts, pages_read_engagement,
       instagram_content_publish, instagram_basic
     - Provide screen recordings/use case descriptions
     - Submit for review
  10. Save App Secret in OpenBao: `bao kv put slp-portal/facebook app_secret=<paste>`

IMPORTANT — two-layer model:
  - FACEBOOK_APP_ID and FACEBOOK_APP_SECRET go in .env (app identity)
  - User page access tokens are generated via OAuth in Postiz UI and stored by Postiz
  - Never put your personal FB password or access token in .env

Env vars:
  FACEBOOK_APP_ID=<app id>
  FACEBOOK_APP_SECRET=<from OpenBao>
  THREADS_APP_ID=<same as FACEBOOK_APP_ID>
  THREADS_APP_SECRET=<same as FACEBOOK_APP_SECRET>

────────────────────────────────────────────────────────────────────────────
10. LINKEDIN
────────────────────────────────────────────────────────────────────────────
Type: OAuth 2.0 / OpenID Connect
Review required: YES — Marketing API requires explicit product approval
Setup time: Days to weeks for marketing API approval

Steps:
  1. Go to linkedin.com/developers
  2. Create app → Company: your LinkedIn company page
  3. Products tab → Request access to:
     - "Share on LinkedIn" (approval required)
     - "Sign In with LinkedIn using OpenID Connect"
  4. Auth tab:
     - Redirect URL: http://localhost:3000/api/socials/linkedin/callback
     - OAuth 2.0 scopes: w_member_social, r_basicprofile
  5. Copy Client ID and Client Secret
  6. Save secret in OpenBao: `bao kv put slp-portal/linkedin secret=<paste>`

Env vars:
  LINKEDIN_CLIENT_ID=<client id>
  LINKEDIN_CLIENT_SECRET=<from OpenBao>

────────────────────────────────────────────────────────────────────────────
11. X (TWITTER)
────────────────────────────────────────────────────────────────────────────
Type: OAuth 2.0 with PKCE
Review required: Developer account approval required
Setup time: Hours to days (developer account review)

Steps:
  1. Go to developer.twitter.com
  2. Sign in → Apply for developer account if needed
  3. Developer Portal → Projects & Apps → Create Project → Create App
  4. App Settings → User authentication settings:
     - OAuth 2.0: Enable
     - App type: Web App
     - Callback URL: http://localhost:3000/api/socials/x/callback
     - Website URL: your site
  5. Scopes: tweet.read, tweet.write, users.read, offline.access
  6. Keys and Tokens tab → OAuth 2.0 Client ID and Client Secret
  7. Save secret in OpenBao: `bao kv put slp-portal/x secret=<paste>`

NOTE: Check developer.twitter.com for current API tier pricing — changed in 2023/2024

Env vars:
  X_CLIENT_ID=<client id>
  X_CLIENT_SECRET=<from OpenBao>

────────────────────────────────────────────────────────────────────────────
12. TIKTOK (Hardest — requires app review)
────────────────────────────────────────────────────────────────────────────
Type: OAuth 2.0 (Content Posting API)
Review required: YES — app review + Content Posting API approval
Setup time: Weeks

Steps:
  1. Go to developers.tiktok.com
  2. Manage Apps → Create App
  3. Products: Add "Content Posting API" + "Login Kit"
  4. Redirect URI: http://localhost:3000/api/socials/tiktok/callback
  5. Scopes: video.upload, video.publish
  6. Submit for app review with use-case description
  7. After approval: copy Client Key and Client Secret
  8. Save secret in OpenBao: `bao kv put slp-portal/tiktok secret=<paste>`

Env vars:
  TIKTOK_CLIENT_ID=<client key>
  TIKTOK_CLIENT_SECRET=<from OpenBao>

────────────────────────────────────────────────────────────────────────────
VALIDATION
────────────────────────────────────────────────────────────────────────────
After setting env vars, run:
  bash downloads/scripts/validate-postiz-providers.sh .env

Then restart Postiz and connect each account via Postiz UI:
  http://localhost:3000 → Settings → Social Accounts

The postiz-provider-health cron job runs daily at 06:30 UTC and will:
  - Check which providers are configured
  - Validate live connections via Postiz API
  - Queue admin in-app notification with setup guidance if anything is missing
  - Use local Ollama to generate step-by-step instructions (no cloud tokens)
